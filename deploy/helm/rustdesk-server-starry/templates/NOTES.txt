Supervision:
- HBBR answers `GET {{ .Values.hbbr.operations.listen }}/healthz` (liveness),
  `/readyz` (readiness) and `/metrics` on the node. Keep it on loopback.
- Point a load balancer or service registry at `/readyz`, never `/healthz`:
  `/readyz` returns 503 while the relay is draining or at capacity, which is
  when new sessions must stop arriving. `/healthz` stays 200 in those states on
  purpose, so a supervisor does not restart a relay that is working correctly.
{{- if .Values.hbbr.serviceMonitor.enabled }}
- The ServiceMonitor scrapes `/metrics` every {{ .Values.hbbr.serviceMonitor.interval }}.
{{- else }}
- Set `hbbr.serviceMonitor.enabled=true` to scrape `/metrics` with the
  Prometheus Operator (requires its CRDs).
{{- end }}
{{- end }}

Scaling out means one release per node: a second replica on the same node
would collide on the fixed ports.
